A draggable, resizable dashboard grid, built as a fully controlled component (`layout` prop + `onLayoutChange`) on the same shared `@keystone-dashboard-layout/core` engine the Vue package uses — drag, resize, multi-select, undo/redo, and breakpoint-aware layouts, zero runtime dependencies.

```sh
npm i @keystone-dashboard-layout/react
```

## Jump in

- **[Guide](/react/guide/introduction/)** — what you get, how it fits together, and where to go next.

:::note[Status]
The `@keystone-dashboard-layout/react` package itself has reached full feature parity with Vue — every phase in its own implementation plan is done, with a real, extensive test suite (unit, mutation, and end-to-end). Documentation is being written incrementally, starting with the Guide; Features, Components, API reference, and a full set of live examples follow the same phase order the Vue docs did. See **[Vue documentation](/vue/)** for the complete reference in the meantime — most of the same concepts apply, expressed the idiomatic React way (controlled component, hooks, a `ref`-based imperative handle) rather than Vue's own `v-model`/composables/`defineExpose`.
:::
