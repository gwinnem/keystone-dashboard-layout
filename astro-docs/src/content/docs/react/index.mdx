A draggable, resizable dashboard grid, built as a fully controlled component (`layout` prop + `onLayoutChange`) on the same shared `keystone-dashboard-layout-core` engine the Vue package uses — drag, resize, multi-select, undo/redo, and breakpoint-aware layouts, zero runtime dependencies.

```sh
npm i keystone-dashboard-layout-react
```

- **[Guide](/react/guide/introduction/)** — install the package and render your first grid in under five minutes.
- **[Features](/react/features/)** — everything the grid does, grouped by category, linked to a live example.
- **[Components](/react/components/)** — `GridLayout` and `GridItem`, every prop, event, and the imperative handle.
- **[API reference](/react/api/)** — interfaces and types exported from the package root.
- **[Examples](/react/examples/)** — 52 interactive, live-running examples — try before you copy.

`keystone-dashboard-layout-react` has reached full feature parity with Vue — every prop/behavior in its own inventory is implemented, with a real, extensive test suite (unit, mutation, and end-to-end).
