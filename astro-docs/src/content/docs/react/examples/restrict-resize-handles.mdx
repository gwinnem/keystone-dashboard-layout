Distinct from [Configurable resize-hint appearance](/react/examples/resize-hint-appearance/)
(`showResizeHandles`, an all-or-nothing show/hide toggle for the
*visible* affordance): this restricts which handles actually
*activate* at all, grid-wide (`GridLayout`'s own `resizeHandles` prop)
or per-item (the layout item's own `resizeHandles` field). Default all
8 (`'n'`/`'s'`/`'e'`/`'w'`/`'ne'`/`'nw'`/`'se'`/`'sw'`). An empty array
(`[]`) is a deliberate, valid "no handle-driven resize for this item"
value, distinct from `isResizable: false` — keyboard arrow-key resize
still works with `[]`; it doesn't with `isResizable: false`.
