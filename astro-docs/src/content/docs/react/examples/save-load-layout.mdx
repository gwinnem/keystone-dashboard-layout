`layout` is already a plain array of plain objects, so
`JSON.stringify`/`JSON.parse` would round-trip it correctly on its own
— no special hook required for the basic case. This example uses the
package's own `useLayoutStorage` hook instead, which wraps that same
pattern (plus the internal `moved` field stripped, and shape
validation on load) behind `load()`/`save()` calls. See [Layout
persistence](/react/api/interfaces/layout-persistence/) for the full
reference, including `useLayoutPresets` for saving/switching between
several named layouts.
