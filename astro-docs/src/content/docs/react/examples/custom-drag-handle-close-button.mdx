Unlike the Vue package, there's no separate exported `CustomDragElement`/`CustomCloseButton`
component to import — since any element can already be a drag handle
or a close button, a plain `<span>`/`<button>` styled however you like
is the whole mechanism. Pairing `dragAllowFrom` with `resizeIgnoreFrom`
on the same selector matters here too: without it, the handle can end
up fighting the resize engine's own edge-proximity detection near a
corner.
