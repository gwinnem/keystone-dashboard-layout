`responsive` enables breakpoint switching using the `breakpoints`/`cols`
props (both default to a standard 7-tier scale — `xxl`/`xl`/`lg`/`md`/`sm`/`xs`/`xxs`).
When the container's measured width crosses a threshold, the layout
regenerates for the new breakpoint's column count, and
`onBreakpointChange` fires with the new breakpoint name and column count.

See [Responsive predefined layouts](/react/examples/responsive-predefined-layouts/)
for full control over what each breakpoint's layout looks like, instead
of relying on auto-generation.
