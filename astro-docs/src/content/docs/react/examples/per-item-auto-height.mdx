`autoHeight` is set on the layout item itself, not as a `GridItem` prop
— `GridItem` only takes `i` and reads everything else from its matching
layout entry. Live-resyncing — it keeps watching the item's own content
via a real `ResizeObserver`, so an item grows or shrinks automatically
as its content changes after mount, not just once when it first
renders. Pairs naturally with dynamic content whose size isn't known
upfront (a loaded chart, an expanding text block, an async list).
