Unlike the Vue package, there's no separate per-item eventBus — every
change is reported through `GridLayout`'s own callback props
(`onLayoutChange`, `onDragStart`/`onDragMove`/`onDragEnd`, and more).
This example diffs each `onLayoutChange` call against the previous
layout to detect moves and resizes; see [GridLayout props](/react/components/grid-layout/props/)
for the complete callback list, including the granular per-phase drag
events (`onDragStart`/`onDragMove`/`onDragEnd`) used alongside it here.
