Applies to item position/size changes and the container's own
`autoSize`-driven height changes — both default to `200`ms / `'ease'`.
Set `transitionDurationMs` to `0` to disable transitions entirely
(useful while dragging live data-driven layouts where every frame's
position should snap immediately, not animate).
