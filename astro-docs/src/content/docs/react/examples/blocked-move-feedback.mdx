Without this callback, `preventCollision` alone gives no feedback about
*why* a drag stopped short — the item just doesn't move, which can look
like a bug rather than intentional collision blocking. Use it to drive
a flash, a shake animation, or a toast, so the block reads as
deliberate.

See [Prevent collision](/react/examples/prevent-collision/) for the
base prop this callback pairs with.
