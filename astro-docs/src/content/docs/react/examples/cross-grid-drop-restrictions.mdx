`disableExternalDrop` has no effect unless `allowCrossGridDrag` is also
set — it only restricts the *incoming* direction. An item can still be
dragged *out* of a grid with both set, into any other
`allowCrossGridDrag` grid that doesn't reject it. `onCrossGridDropRejected`
fires on the target grid with the rejected item's id and the
`layoutId` it came from.
