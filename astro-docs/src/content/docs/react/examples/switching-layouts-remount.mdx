Switching between entirely different layouts is just a normal
`setLayout` call — no remount needed, and the component correctly
reacts to the wholesale replacement. A `key` change forcing a real
remount (React's own equivalent of Vue's `:key`) is a different,
narrower tool: useful for resetting *internal* component state (an
in-progress drag, measured width, undo history) that a data change
alone wouldn't touch, not something to reach for by default just to
change what's displayed.
