Setting `showCloseButton` on `GridLayout` (rather than on every
individual layout item) controls the default for every item that
doesn't set its own — a layout item's own `showCloseButton` field
always overrides it, same as `isDraggable`/`isResizable`/`isBounded`.
Toggling the control above demonstrates exactly this: no item in this
example sets its own `showCloseButton`, so all three follow the
layout's default at once.

Unlike the Vue package, there's no separate exported close-button
component to swap in — `onItemClose` deliberately doesn't remove
anything from `layout` itself, so pairing it with your own `.filter()`
(as this example does) is the whole customization surface.
