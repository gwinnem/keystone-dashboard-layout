Both methods are exposed on the [imperative handle](/react/api/interfaces/imperative-handle/),
reached through a `ref` — the same pattern as `compactNow()`/
`rearrange()`/`duplicateItem()`. `scrollToItem` scrolls the item's
nearest scrollable ancestor; `focusItem` additionally moves keyboard
focus to it, useful for jumping straight into keyboard move/resize on a
specific item without tabbing through everything before it.
