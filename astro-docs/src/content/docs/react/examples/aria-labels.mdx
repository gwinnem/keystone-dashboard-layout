Deliberately a small, fixed set of overridable strings, not a full i18n
system — no pluralization, no locale negotiation. Wire your own
translation function's output into `ariaLabels` for real i18n
integration; this just makes the strings *reachable* instead of a
hardcoded English literal. Three layers merge, each only overriding the
keys it actually sets: built-in English defaults ← `GridLayout`'s own
`ariaLabels` (grid-wide) ← a specific layout item's own `ariaLabels`
field (per-item) — override just one string grid-wide, or just one
string on one item, without re-supplying every other key.
