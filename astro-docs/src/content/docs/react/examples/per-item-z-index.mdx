`null`/unset (the default) means no override at all — the item falls
back to the library's own implicit handling (static items sit at
`-1`, an actively resizing item briefly rises to `3`, everything else
uses normal DOM-order stacking). An explicit value set on the layout
item always wins over both of those, regardless of the item's current
static/resizing state — useful for pinning one panel permanently above
every other, including while others are mid-drag or mid-resize.
