Each `GridLayout` instance owns its own `layout` state and Context —
grids never share state, so there's nothing to namespace or configure.

:::caution[Not the same as dragging between grids]
This just shows two grids side by side. For actually dragging an item
*from* one grid *into* another, see `allowCrossGridDrag`/
`disableExternalDrop` on [GridLayout props](/react/components/grid-layout/props/)
— cross-grid dragging works the same way, using the source grid's own
drag event and the target grid's layout array.
:::
