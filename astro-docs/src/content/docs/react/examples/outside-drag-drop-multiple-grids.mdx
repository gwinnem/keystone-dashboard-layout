No coordination is needed between the two grids — each independently
listens for a drop over its own root element and calls its own
`onOutsideDrop` only if the release actually happened over it.
Releasing between them, or over neither, drops nothing on either side.

See [Drag, drop from outside](/react/examples/outside-drag-drop/) for
the single-grid version.
