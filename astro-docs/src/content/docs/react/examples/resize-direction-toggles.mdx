Unlike [Restricting resize handles to specific edges](/react/examples/restrict-resize-handles/)
(a fixed `resizeHandles` array set once, on the layout item), every
direction here is independently switchable — unchecking every toggle
leaves `resizeHandles` as an empty array (`[]`), a deliberate, valid
"no handle-driven resize for this item" value, distinct from
`isResizable: false`. Keyboard arrow-key resize still works with `[]`;
it doesn't with `isResizable: false`.
