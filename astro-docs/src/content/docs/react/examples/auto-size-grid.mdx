`autoSize` is `true` by default — most consumers never need to think
about it. It's worth knowing about mainly for the opposite case: set
`autoSize={false}` if you want a fixed-height scrollable grid instead
of one that grows to fit its content.

:::tip[Prefer heightMode for finer control]
`autoSize` is the original boolean toggle; `heightMode` is the newer,
more expressive replacement (`'auto'`/`'fixed'`/`'scroll'`/`'fit'`) —
see [GridLayout props](/react/components/grid-layout/props/) for the
full set of modes, including the `'scroll'`/`'fit'` options this
boolean toggle can't express on its own.
:::
