Both props cascade from `GridLayout` to every layout item that doesn't
set its own — the same inherit pattern as `isDraggable`/`showCloseButton`.
For a fully custom look beyond just a color, see the `renderResizeHandle`
render prop on [GridItem props](/react/components/grid-item/props/),
which renders arbitrary content (an icon, not just a colored dot) per
handle instead.
