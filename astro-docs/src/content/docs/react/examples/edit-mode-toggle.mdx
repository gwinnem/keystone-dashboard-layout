`enableEditMode` cascades to every layout item that doesn't set its own
override — a "view mode" toggle for the whole grid without needing to
set the field on every item individually. A layout item can still set
its own `enableEditMode` field to override the grid-wide default for
just itself, the same inherit pattern `isDraggable`/`isResizable`/`showCloseButton`
use.
