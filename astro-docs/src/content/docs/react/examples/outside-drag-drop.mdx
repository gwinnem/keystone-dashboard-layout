The source element just needs `draggable="true"` and a real
`onDragStart` handler setting some `dataTransfer` payload — no
special integration with the grid required on that side.
`onOutsideDrop` fires with the grid position/size the drop landed at;
it's up to your own handler to actually push a new layout entry (the
library doesn't assume what you want to do with the drop).
