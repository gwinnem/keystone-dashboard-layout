Setting `useBorderRadius`/`borderRadiusPx` on `GridLayout` cascades to
every layout item that doesn't set its own (unset, the default), the
same inherit pattern as `isDraggable`/`isResizable`. Setting either
field directly on a layout item overrides that inherited default for
just that one item.
