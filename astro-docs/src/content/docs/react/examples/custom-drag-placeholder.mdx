`GridLayout`'s own `renderPlaceholder` prop — the React render-prop
equivalent of Vue's own `#placeholder` scoped slot — renders fully
custom content at the drop target during *any* drag or resize, in-grid
or outside-drop, instead of the default plain, dashed-outline box. The
dragged/resized item itself still moves live to its in-progress
position on every tick, exactly as before; `renderPlaceholder` only
customizes the separate box shown at *where it will land* once the
gesture ends.

It receives two plain arguments — the live target `{ x, y, w, h }` (or
`null` when nothing is active) and a boolean `isDragging` — matching
this package's own `renderResizeHandle` convention of plain function
arguments over a single context object:

```tsx
renderPlaceholder={(placeholder, isDragging) => (
  <div className="custom-placeholder">
    {isDragging && placeholder && (
      <span>drop at x:{placeholder.x} y:{placeholder.y}</span>
    )}
  </div>
)}
```

Positioning and sizing are still handled automatically — the returned
content is placed inside an already-correctly-positioned wrapper; only
what's shown *inside* that box is yours to customize. Leaving this prop
unset renders the existing plain box, exactly as before this prop
existed.

If you want a visual indicator with a different visual language
entirely — edge-alignment guide lines or labeled distance badges rather
than a box at the drop target — see
[`showAlignmentGuides`](/react/components/grid-layout/props/) and
[`showSpacingGuides`](/react/components/grid-layout/props/) instead.
