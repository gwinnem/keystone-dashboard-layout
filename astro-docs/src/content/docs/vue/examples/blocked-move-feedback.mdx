Without this event, `preventCollision` alone gives no feedback about
*why* a drag stopped short — the item just doesn't move, which can look
like a bug rather than intentional collision blocking. Use the event to
drive a flash, a shake animation, or a toast, so the block reads as
deliberate.

See [Prevent collision](/vue/examples/prevent-collision/) for the base
prop this event pairs with.
