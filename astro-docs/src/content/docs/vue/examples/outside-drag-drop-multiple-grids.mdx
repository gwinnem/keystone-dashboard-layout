No coordination is needed between the two grids — each independently
listens for a drop over its own root element and fires its own
`item-dropped-from-outside` only if the release actually happened over
it. Releasing between them, or over neither, drops nothing on either
side.

See [Drag, drop from outside](/vue/examples/outside-drag-drop/) for the
single-grid version, and
[outsideDropAccept & readOutsideDropPayload](/vue/examples/outside-drop-accept-payload/)
for filtering which drags a specific grid accepts.
