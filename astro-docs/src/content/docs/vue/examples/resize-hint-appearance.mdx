Both props cascade from `GridLayout` to every `GridItem` that doesn't
set its own — the same inherit pattern as `isDraggable`/`showCloseButton`.
For a fully custom look beyond just a color, see
[GridItem slots → #resize-handle](/vue/components/grid-item/slots/),
which renders arbitrary content (an icon, not just a colored dot) per
handle instead.
