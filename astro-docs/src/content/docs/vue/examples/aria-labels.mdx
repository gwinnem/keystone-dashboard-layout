Deliberately a small, fixed set of overridable strings, not a full i18n
system — no pluralization, no locale negotiation. Wire your own
translation function's output into these props for real i18n
integration; this just makes the strings *reachable* instead of a
hardcoded English literal. Three layers merge, each only overriding the
keys it actually sets: built-in English defaults ← `GridLayout`'s own
`ariaLabels` (grid-wide) ← a specific `GridItem`'s own `ariaLabels`
(per-item) — override just one string grid-wide, or just one string on
one item, without re-supplying every other key.

See [Accessibility scope](/vue/guide/project/accessibility/) for the
full picture of what this library's keyboard/screen-reader support
does and doesn't cover.
