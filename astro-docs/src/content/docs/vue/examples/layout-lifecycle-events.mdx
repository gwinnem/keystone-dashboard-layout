`layout-ready` is the one worth knowing about specifically: it fires
exactly once, after the container's width is actually known and every
item has had a chance to settle its own size — the first point where
inspecting final positions/sizes is reliable, rather than reading
values that are still mid-measurement. `layout-updated` fires more
often — once during mount, and again after every subsequent mutation
(drag/resize completion, item add/remove, align/distribute, undo/redo).

See [GridLayout events](/vue/components/grid-layout/vue-events/) for
the full event reference.
