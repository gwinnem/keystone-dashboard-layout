`collisionMode` is `'push'` (the default) or `'swap'`. With `'swap'`,
dropping an item onto exactly one other non-static item that fits into
the dragged item's starting cell trades the two places. Anything else
(several items under the pointer, a static item, or the other item not fitting
the starting cell) falls back to the usual push. It only affects dragging, and is
ignored while `preventCollision` is on.
See [`collisionMode`](/vue/components/grid-layout/props/) in the props reference.
