No special composable is required for the basic case — `layout` is
already a plain array of plain objects, so `JSON.stringify`/`JSON.parse`
round-trips it correctly on its own. The package does ship a
`useLayoutStorage` composable for the common save/load-against-`Storage`
pattern shown above, and `useLayoutPresets` for saving/switching between
several named layouts — see [Named layout presets](/vue/examples/named-presets/).
