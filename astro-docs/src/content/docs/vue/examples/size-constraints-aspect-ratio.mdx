All four size-constraint props default to `1`/`Infinity` respectively
(effectively unconstrained) and apply during both mouse/touch resize
and [keyboard resize](/vue/guide/project/accessibility/). `preserveAspectRatio`
locks the width/height ratio at whatever it was when the resize
started — resizing from any handle keeps that ratio, not just the
corner handles.
