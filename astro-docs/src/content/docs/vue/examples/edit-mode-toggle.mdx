`enableEditMode` cascades to every `GridItem` that doesn't set its own
override — a "view mode" toggle for the whole grid without needing to
bind the prop on every item individually. A `GridItem` can still set
its own `enableEditMode` to override the grid-wide default for just
itself, the same inherit pattern `isDraggable`/`isResizable`/`showCloseButton`
use.
