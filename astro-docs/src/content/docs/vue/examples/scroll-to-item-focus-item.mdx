Both methods are exposed on the `GridLayout` instance, reached through
a template `ref` — the same pattern as `compactNow()`/`rearrange()`/
`duplicateItem()`. `scrollToItem` scrolls the item's nearest scrollable
ancestor; `focusItem` additionally moves keyboard focus to it, useful
for jumping straight into [keyboard move/resize](/vue/guide/project/accessibility/)
on a specific item without tabbing through everything before it.
