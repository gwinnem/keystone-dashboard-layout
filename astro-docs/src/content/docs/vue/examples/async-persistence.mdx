`useAsyncLayoutStorage` is the asynchronous sibling of
[`useLayoutStorage`](/vue/examples/save-load-layout/). Hand it any
`IAsyncLayoutStorage`: `createHttpStorage`, `createIndexedDbStorage`,
`createMemoryAsyncStorage`, or your own three-method object. This demo uses an
in-memory stand-in for a server so you can pick a latency, or tick "Server is
down" and save, to see a failure reported.

Nothing it returns rejects. A failing store sets `error` (and calls `onError`)
and the method resolves `false`. Writes are queued, so a slow earlier save can
never overwrite a later one, and `isLoading` / `isSaving` stay `true` until the
last queued operation is done.
