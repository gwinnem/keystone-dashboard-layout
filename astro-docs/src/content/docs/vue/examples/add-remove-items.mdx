`y: Infinity` is a common placement convention — the compaction pass
that runs immediately after settles the new item into the first
available gap, so there's no need to compute a real starting position
yourself. `remove-grid-item` fires when the close button is clicked (`showCloseButton`
is on) — pair it with a `.filter()` the same way as above.
