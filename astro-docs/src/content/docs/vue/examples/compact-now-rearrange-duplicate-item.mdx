`compactNow()` always forces compaction, regardless of the ambient
`verticalCompact`/`compactType` setting — the entire point of a manual
"tidy up" trigger is that it works even when auto-compaction is
otherwise disabled. `rearrange()` is the same underlying operation
under a different name for call sites that read more naturally that
way. `duplicateItem(id)` clones an existing layout entry into the first
available free slot — collision-safe, no manual position math needed,
the same convention `y: Infinity` uses for [adding items](/vue/examples/add-remove-items/).
