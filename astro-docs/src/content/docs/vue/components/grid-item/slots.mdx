---
title: GridItem Slots
description: The default slot, the #header slot, and the custom resize-handle slot GridItem exposes.
---

## Default slot

Anything you render inside `<GridItem>` lands here — text, images,
forms, a chart component, another Vue component entirely. `GridItem`
doesn't style it.

```vue
<GridItem v-bind="item">
  <MyChartComponent :data="item.data" />
</GridItem>
```

The slot receives one scope prop:

| Prop | Type | Description |
|---|---|---|
| `style` | `Record<string, string \| number>` | The same computed position/size style `GridItem` applies to its own root element — rarely needed, but available if a child needs to match it exactly (e.g. an absolutely-positioned overlay). |

```vue
<GridItem v-bind="item" v-slot="{ style }">
  <div :style="style">Matches the item's own computed size exactly</div>
</GridItem>
```

## `#header` slot

An optional, separate header region above the default slot's own
content — only affects layout when actually provided; the no-header
case renders identically to before this slot existed.

```vue
<GridItem v-bind="item">
  <template #header>
    <strong>{{ item.title }}</strong>
  </template>
  {{ item.body }}
</GridItem>
```

When used, `GridItem` switches to a vertical flex layout: the header
shrinks to fit its own content, and the default slot's content (now
wrapped in its own scrollable region) takes whatever space remains —
content taller than the item's own fixed pixel height scrolls
internally instead of pushing the item's real size (which the grid's
own layout math depends on staying accurate).

## `#resize-handle` slot

Custom content for each of the 8 resize handles (edges + corners) — a
fully custom render (an icon, not just a color) rather than only a
color/visibility toggle. Renders inside the same small hit-area
`showResizeHandles`/`resizeHandleColor` already use; both mechanisms can
be combined, or the slot used alone for a fully custom look. See
[Multi-select & group move/resize](/vue/examples/multi-select-group-move-resize/),
which also demonstrates this slot.

```vue
<GridItem v-bind="item">
  {{ item.label }}
  <template #resize-handle="{ edge }">
    <MyResizeIcon :edge="edge" />
  </template>
</GridItem>
```

The slot receives one scope prop:

| Prop | Type | Description |
|---|---|---|
| `edge` | `'n' \| 's' \| 'e' \| 'w' \| 'ne' \| 'nw' \| 'se' \| 'sw'` | Which of the 8 resize handles this particular slot instance is rendering into — the slot is invoked once per handle, each with its own `edge` value, so different content per edge/corner is possible if wanted. |

Not rendered at all when the item isn't resizable (`isResizable` false,
or `isStatic`) — same condition that already gates whether the resize
hints render at all.
