---
title: Components
description: GridLayout and GridItem — the two components this library exports, plus small utility components.
---

The package exports these from its main entry point:

| Component | Purpose |
|---|---|
| [`GridLayout`](/vue/components/grid-layout/props/) | The grid container — owns the layout array, breakpoints, and collision/compaction logic. |
| [`GridItem`](/vue/components/grid-item/props/) | A single draggable/resizable cell, rendered inside `GridLayout`'s default slot. |
| `CustomCloseButton` | The exact close button `GridItem` renders internally for `showCloseButton` — exported for standalone reuse. See [Styling → GridItem](/vue/components/styling/css-grid-item/). |
| `CustomDragElement` | A standalone drag-handle widget, not used internally by the library — pair it with `GridItem`'s `dragAllowFrom` prop. See [Custom drag handle & close button](/vue/examples/custom-drag-handle-close-button/). |

```ts
import {
  GridLayout,
  GridItem,
  CustomCloseButton,
  CustomDragElement,
} from '@keystone-dashboard-layout/vue';
```

There's no default export — always import by name. See [Installation](/vue/guide/installation/)
if you haven't added the package yet.
