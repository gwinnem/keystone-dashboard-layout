---
title: Pluggable compaction (ICompactor)
description: The interface behind the compactor prop, its context object, and the five built-in strategies exported alongside it.
---

```ts
interface ICompactor {
  readonly type: string;
  compact(layout: TLayout, cols: number, context: ICompactorContext): TLayout;
}
```

| Member | Description |
|---|---|
| `type` | A short, descriptive name for this strategy — informational only (e.g. for logging); never read by `GridLayout` itself. |
| `compact(layout, cols, context)` | Compacts a layout, **returning a new array** — must not mutate the input `layout` or any of its items in place. |

## `ICompactorContext`

```ts
interface ICompactorContext {
  compactType: ECompactType;
  minPositions?: Record<string | number, { x?: number; y?: number }>;
}
```

| Field | Description |
|---|---|
| `compactType` | Which built-in strategy currently applies — informational, read from `GridLayout`'s own `compactType` prop at the moment compaction runs. A custom compactor decides for itself whether/how to use this; nothing enforces it. |
| `minPositions` | Present only during a `restoreOnDrag`-gated compaction (drag end) — the pre-drag position each item shouldn't rise/shift any tighter than. Absent for every other trigger (resize end, add/remove, mount, breakpoint change, `compactNow()`/`rearrange()`), and for the two `*_OVERLAP` types. |

## The five built-in strategies

Exported individually, as a starting point for a custom compactor to
delegate back to for part of a layout (e.g. compact everything except
one pinned row) rather than reimplementing standard compaction from
scratch:

```ts
import {
  verticalCompactor,
  horizontalCompactor,
  noCompactor,
  verticalOverlapCompactor,
  horizontalOverlapCompactor,
  getCompactor,
} from 'keystone-dashboard-layout-vue';
```

| Export | Backs |
|---|---|
| `verticalCompactor` | `ECompactType.VERTICAL` (the default) |
| `horizontalCompactor` | `ECompactType.HORIZONTAL` |
| `noCompactor` | `ECompactType.NONE` |
| `verticalOverlapCompactor` | `ECompactType.VERTICAL_OVERLAP` |
| `horizontalOverlapCompactor` | `ECompactType.HORIZONTAL_OVERLAP` |
| `getCompactor(compactType)` | Looks up the built-in `ICompactor` matching a given `ECompactType` — the same mapping `GridLayout` itself uses internally when the `compactor` prop isn't set. |

See [Pluggable compaction](/vue/examples/pluggable-compaction/) for a
full working custom compactor, and [ECompactType](/vue/api/enums/compact-type/)
for what each built-in strategy actually does.
