Forward-looking — what's suggested next, not a commitment. For what's
already built, see [Features](/vue/features/) and the
[Changelog](/vue/guide/changelog/).

## A Nuxt module, paired with a real SSR audit

One concrete SSR-breaking spot (an unguarded `navigator.userAgent` read
inside a template-bound computed) has already been found and fixed —
but that was one specific instance checked, not the exhaustive sweep a
real audit would need before shipping a dedicated Nuxt wrapper around
the rest of the codebase.
