> **calcColWidth**(`containerWidth`, `marginLeftRight`, `cols`): `number`

Calculating the Column width.

## Parameters

### containerWidth

`number`

The width of the GridLayout container

### marginLeftRight

`number`

Left snd Right margin value.

### cols

`number`

Number of columns defined in the layout.

## Returns

`number`

The new column width.
