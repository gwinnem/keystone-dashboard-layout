> **sortBreakpoints**(`breakpoints`): `string`[]

Given breakpoints, return an array of breakpoints sorted by width. This is usually
e.g. ['xxs', 'xs', 'sm', ...]

## Parameters

### breakpoints

[`TBreakpoints`](/core/api/reference/types/tbreakpoints/)

Key/value a pair of breakpoint names to widths.

## Returns

`string`[]

Sorted breakpoints.
