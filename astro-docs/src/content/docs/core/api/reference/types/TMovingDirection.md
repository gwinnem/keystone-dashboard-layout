> **TMovingDirection** = keyof *typeof* [`EMovingDirections`](/core/api/reference/enums/emovingdirections/)

A single direction key from [EMovingDirections](/core/api/reference/enums/emovingdirections/) (`'UP' | 'DOWN' |
'LEFT' | 'RIGHT'`), used to describe which way a colliding item is being
pushed in `move-helper.ts`'s collision-resolution logic.
