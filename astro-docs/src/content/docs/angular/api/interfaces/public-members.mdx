---
title: Public members (GridLayoutComponent)
description: The public methods and fields GridLayoutComponent exposes — the Angular equivalent of Vue's defineExpose or React's imperative handle.
---

Angular has no separate "imperative handle" type the way React does —
these are simply the `public` methods and fields on the
`GridLayoutComponent` class itself, reached via a template reference
variable:

```ts
import { Component, ViewChild } from '@angular/core';
import { GridLayoutComponent, GridItemComponent } from '@keystone-dashboard-layout/angular';

@Component({
  standalone: true,
  imports: [GridLayoutComponent, GridItemComponent],
  template: `
    <button (click)="grid.compactNow()">Tidy up</button>
    <kdl-grid-layout #grid [layout]="layout" (layoutChange)="layout = $event">
      <!-- ... -->
    </kdl-grid-layout>
  `,
})
export class DashboardComponent {
  @ViewChild('grid') gridRef!: GridLayoutComponent;
  // ...
}
```

A template reference variable (`#grid`, used directly in the template
above via `grid.compactNow()`) works for calling a method from within
the same template. Reach the same instance from your own component
class instead via `@ViewChild('grid')`, as shown.

## Compaction

| Member | Type | Description |
|---|---|---|
| `compactNow` | `(): void` | Re-runs compaction on demand — forces real compaction even when `compactType` is `NONE`, unlike the automatic per-tick compaction. |
| `rearrange` | `(): void` | Alias for `compactNow()`. |

## Items

| Member | Type | Description |
|---|---|---|
| `duplicateItem` | `(id: string \| number): string \| number \| null` | Clones the item, placing the copy directly below the source. Returns the new item's id, or `null` if `id` doesn't match. |
| `scrollToItem` | `(id: string \| number): void` | Scrolls the item into view, if currently rendered. A no-op (not a throw) on a missing id. |
| `focusItem` | `(id: string \| number): void` | Moves keyboard focus to the item, if currently rendered and focusable. |

## Selection (`multiSelect`)

| Member | Type | Description |
|---|---|---|
| `selectedItemIds` | `Set<string \| number>` | The currently-selected item ids. A `Set`, not an array — for O(1) `.has()` lookups. Always empty when `multiSelect` is off. |
| `selectItem` | `(id: string \| number): void` | Selects exactly this item, replacing any existing selection. |
| `deselectItem` | `(id: string \| number): void` | Removes this item from the selection, if present. |
| `toggleItemSelection` | `(id: string \| number): void` | Adds if absent, removes if present. |
| `clearSelection` | `(): void` | Empties the selection entirely. |
| `alignSelected` | `(edge: TAlignEdge): void` | Aligns every selected item to the given edge/center of the anchor (the first-selected item, which never moves). A no-op with fewer than 2 items selected. |
| `distributeSelected` | `(axis: TDistributeAxis): void` | Evenly spaces selected items along the given axis; the two outermost stay fixed. A no-op with fewer than 3 items selected. |

## Undo/redo (`enableUndoRedo`)

| Member | Type | Description |
|---|---|---|
| `undo` | `(): void` | Reverts to the most recently captured pre-gesture snapshot. A no-op when `canUndo` is `false`. |
| `redo` | `(): void` | Reapplies the most recently undone state. A no-op when `canRedo` is `false`. |
| `canUndo` | `boolean` | Whether `undo()` currently has a snapshot to revert to. |
| `canRedo` | `boolean` | Whether `redo()` currently has a snapshot to reapply. |

:::note[canUndo/canRedo are plain fields, not signals or observables]
Reading `gridRef.canUndo` from your own component class won't
automatically re-render your own template when it changes — Angular's
change detection picks it up on the *grid's own* next check (already
triggered internally via `markForCheck()` whenever these change), but
if you're mirroring the value into your own component's state for a
disabled-button binding, you'll need your own mechanism to know when
to re-read it, the same class of consideration React's snapshot-style
`canUndo`/`canRedo` on its own imperative handle requires.
:::

## Export

| Member | Type | Description |
|---|---|---|
| `exportLayoutAsSvg` | `(options?: IExportLayoutAsSvgOptions): string` | Renders the current layout as a standalone SVG string, pre-filled with this grid's own `colNum`/`rowHeight`/`margin`/measured width. |

## Other public fields

| Member | Type | Description |
|---|---|---|
| `containerWidth` | `number` | The measured container pixel width. |
| `layouts` | `Record<string, TLayout>` | The per-breakpoint layout cache (`responsiveLayouts`), kept current as breakpoints are entered — useful for persisting a full responsive layout set. |
| `lastBreakpoint` | `TBreakpoint \| null` | The breakpoint `responsive` mode most recently resolved to. `null` until the first real measurement, or whenever `responsive` is off. |
| `resolvedLayoutId` | `string` | This grid's own resolved `layoutId` — either the `@Input()` value, or an auto-generated one. |
