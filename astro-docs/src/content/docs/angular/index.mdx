A draggable, resizable dashboard grid, built as standalone components
(`layout` `@Input()` + `layoutChange` `@Output()`) on the same shared
`keystone-dashboard-layout-core` engine the Vue and React packages
use — drag, resize, multi-select, undo/redo, and breakpoint-aware
layouts, with minimal runtime dependencies beyond Angular itself and
RxJS (`tslib` and the shared `core` package).

```sh
npm i keystone-dashboard-layout-angular
```

## Jump in

- **[Guide](/angular/guide/introduction/)** — install the package and render your first grid in under five minutes.

- **[Examples](https://kdla.winnem.tech)** — 57 interactive, live-running examples in a standalone Angular app, each with an editable StackBlitz playground.

:::note[Status]
The `keystone-dashboard-layout-angular` package itself has reached
full feature parity with Vue and React — every item in its own prop
inventory is implemented, with a real, extensive unit/component test
suite (Chromium/Firefox/WebKit) all configured. All 57 of this
package's own interactive examples have been ported, though they live
in a separate, standalone Angular CLI app rather than as embedded Astro
islands here (see [Features](/angular/features/) for why). The Guide,
Features, Components, and API reference are all written; the concepts
are the same as in the **[Vue](/vue/)** and **[React](/react/)**
documentation, expressed the idiomatic Angular way (standalone
components, `@Input()`/`@Output()`, a DI-scoped event bus,
`providedIn: 'root'` services) rather than Vue's `v-model`/composables
or React's hooks/imperative handle.
:::
